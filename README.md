# Market Terminal

Crypto futures market-analysis dashboard. Single page (`index.html`), runs in the browser, no server.

Layers (Step 1+2): order book imbalance, flow, funding and open interest, VWAP, volume spike, RSI, market structure, liquidity sweeps, market regime, and a NO TRADE filter.

Data: Binance Futures public API. Not financial advice, no profit or accuracy guarantee.

Next: backtest based probability and expected value, AI summary.
